RAG Chatbot Integration

Documentation Assistant powered by RAG

How to Use the Chatbot

  • The chat widget is implemented as a React component in frontend-ai-book/src/components/ChatWidget/ChatWidget.jsx
  • It connects to the backend API at http://localhost:8000/
  • Features include real-time streaming responses, citation support, and session management
  • To see it in action, you need to integrate it into a Docusaurus site or React application

API Endpoints

Backend Server: Running at http://localhost:8000/

Health Check: GET /health

Chat: POST /chat (query parameter)

Chat with Selection: POST /chat_with_selection (query and selected_text parameters)

Streaming Chat: GET /chat/stream (query parameter)

Streaming with Selection: GET /chat_with_selection/stream (query and selected_text parameters)

Integration Instructions

To integrate the chat widget into a Docusaurus site:

  1. Install the required dependencies in your Docusaurus project
  2. Copy the ChatWidget.jsx component to your Docusaurus src/components directory
  3. Import and use the component in your desired layout or page
  4. Ensure your backend server is running at the configured URL
